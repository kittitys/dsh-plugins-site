dsh-mem0-memory

把会话记忆自动存进本地的 mem0 向量库，新会话自动召回—— 换对话不再失忆。插件本体 + 导入/搜索 CLI + 本地服务，三件套一起装。

v0.1.6 MIT DSH 0.1.x / 0.2.x 中文优化 数据本地
npm GitHub README Releases

它解决什么问题

Agent 的记忆通常活不过一次会话。这个插件在每一轮对话前，把与当前问题相关的旧记忆召回并注入上下文； 在会话结束时，把新增内容增量写回本地记忆库。你不需要改变使用习惯——装上、重启一次 DSH，它就在后台工作。

特点

混合检索

语义向量 + 关键词 BM25 双通道。意思相近的和字面对得上的，都能捞回来。

中文开箱即用

jieba 分词 + 按输入语言提取事实 + DeepSeek 适配补丁；补丁是运行时挂载，不改 mem0 安装，升级不丢。

增量导入

按会话记录 checkpoint，只处理新增内容，不重复烧 token。

数据留在本地

记忆库（Qdrant + SQLite）完全在你自己的磁盘上，个人数据不上云。

故障可降级

记忆服务挂掉不影响聊天；embedding 服务抖动时自动降级为关键词检索，并在注入块里标注。

工作区隔离

标记为 0_ 的工作区不入库也不召回——目录名、配置名单、或在界面里改的工作区标题都算。

安装

# 1) 装进当前 DSH profile（web）
dsh plugin --profile web add dsh-mem0-memory

# 2) 初始化记忆服务（首次）
npx dsh-mem0-memory-setup --init

# 3) 重启 DSH web —— 之后每轮对话自动召回、每次结束自动写回

首次导入历史会话：dsh-mem0-import --since-last； 主动搜索记忆：dsh-mem0-search "关键词"。完整说明见 README。

兼容性

DSH 版本状态

技术底色

  • 记忆引擎：mem0（本地向量库 Qdrant + SQLite 历史表）
  • 召回时机：agent/pre-step 钩子，同步注入；单次 HTTP 查询，无多轮 agent 循环
  • 零第三方 JS 依赖：插件本身不引入任何 npm 依赖，只调本地 HTTP
  • 导入来源：DSH 自己的会话转录（zstd 压缩的 JSONL），解析后按批次写入
